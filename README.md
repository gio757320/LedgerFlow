# LedgerFlow

Multi-tenant accounting platform for the firm (bookkeeping & GL, tax, payroll).

## Folders
- prototype/ — HTML prototypes (login, firm dashboard, client portal)
- docs/      — specs, requirements, architecture notes
- design/    — mockups, screenshots, visual references
- feedback/  — review notes before each next phase

## Next modules under consideration
- Client account detail page
- General ledger / chart of accounts
- Payroll management
- Tax filing workflow
- Admin-only report generation
